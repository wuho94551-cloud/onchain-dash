폰 알림

사이트를 꺼둬도 텔레그램으로 알림을 받는 설정이에요. 무료 Cloudflare 워커가 1분마다 확인해서 보내줘요. 처음 한 번만 아래 순서대로 만들면 돼요.

1. 알림 조건

미리보기를 누르면 지금 시점에 워커가 보낼 메시지를 여기 보여줘요. 지갑은 최근 24시간 이동을 보여줘요. 텔레그램으로 보내지는 않아요.

2. 워커에 넣을 설정값 (CONFIG)

위 조건을 바꾸면 자동으로 바뀌어요. 조건을 바꾼 뒤에는 Cloudflare의 CONFIG 값도 이걸로 바꿔줘야 해요.

워커 코드 받기 (odesk-alert.js)

3. 처음 한 번 만들기

  1. 텔레그램 봇 만들기. 텔레그램에서 @BotFather를 찾아 /newbot을 보내고 이름을 정하면 토큰(123456:ABC…)을 줘요. 이 토큰은 어디에도 붙여넣지 말고 6번에서 Cloudflare에만 넣어요.
  2. chat id 알아내기. 만든 봇에게 아무 메시지나 보낸 뒤, 브라우저에서 https://api.telegram.org/bot토큰/getUpdates를 열면 "chat":{"id":123456789 숫자가 보여요. 위 칸에 넣어요.
  3. Cloudflare 가입. cloudflare.com에서 무료로 가입해요. 카드 등록은 필요 없어요.
  4. 워커 만들기. 대시보드 → Workers & Pages → Create → "Hello World" 워커를 만든 뒤 Edit code를 눌러 내용을 전부 지우고 odesk-alert.js 내용을 붙여넣고 Deploy.
  5. KV 만들기. Storage & Databases → KV → Create namespace (이름 아무거나). 워커 → Settings → Bindings → Add → KV namespace, 변수 이름은 STATE.
  6. 비밀값 넣기. 워커 → Settings → Variables and Secrets → Add: 종류 Secret, 이름 TG_TOKEN, 값은 봇 토큰. 다시 Add: 종류 Text, 이름 CONFIG, 값은 위 2번의 설정값.
  7. 1분마다 돌게 하기. 워커 → Settings → Trigger Events → Add → Cron Triggers → * * * * *.
  8. 확인. 워커 주소 뒤에 /test를 붙여 열면 텔레그램으로 "연결됐어요"가 와요. /run은 지금 한 번 확인한 결과를 보여줘요.

  • 김프: 업비트 원화 가격 ÷ (Bybit 현물 가격 × open.er-api.com 환율) − 1. 업비트에 원화 마켓이 있는 코인만.
  • 지갑: Blockscout(Base·Ethereum·Arbitrum·Polygon) 토큰 이동. 받는 쪽이 거래소로 태그된 주소면 🚨 거래소 입금으로 보내요. 처음 1분은 기준점만 저장하고 그 뒤 이동부터 알려요.
